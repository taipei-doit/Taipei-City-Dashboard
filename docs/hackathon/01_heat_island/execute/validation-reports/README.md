# Validation Reports

每個組件的快速驗證報告存放於此目錄。

## 命名規則

```
component-{N}-quickval.md
```

其中 `N` 為組件編號（1-10）。

## 如何產生報告

在 Claude Code 中觸發 `component-quick-validator` skill：

```
快速驗證組件 4
```

或

```
validate component 4
```

## 報告格式

詳見 `.agents/skills/component-quick-validator/SKILL.md` Phase 4 章節。
