# Demo Script

## 5-minute story arc

### 1. Set the problem
“When heat rises, city teams need to know where to act first.”

### 2. Show the map
Highlight:
- exposure,
- vulnerability,
- resource gaps.

### 3. Show the ranking
Explain why one or two districts rise to the top.

### 4. Show the AI explanation
Use AI only to summarize and explain the validated indicators.

### 5. End with the PR wedge
Explain what reusable module could land back in the dashboard repo.

## Demo talking points
- This is a public decision tool, not a chatbot.
- The dashboard works even without AI.
- The AI layer only adds explanation.
- The project is designed to become a GitHub issue and a PR-able module.

## One-line closing
“This helps planners decide where to prioritize support, using official data and a reusable dashboard module.”
