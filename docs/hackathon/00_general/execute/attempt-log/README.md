# Attempt Log

This folder records the topic directions we have already explored, so future planning does not loop back to the same dead ends.

## Current rule

- Read this folder before proposing a new hackathon topic.
- Do not re-open a parked idea unless the revisit condition is met.
- If a topic is listed here, assume it has already been considered at least once.

## Status legend

- **Active**: still in play.
- **Parked**: useful, but not the current lead.
- **Rejected**: not worth pursuing unless new evidence appears.
- **Revisit only if**: explicit trigger that justifies coming back.
