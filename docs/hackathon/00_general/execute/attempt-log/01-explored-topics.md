# Explored Topics

## 1. Heat island + vulnerable groups

- **Status:** Active
- **Why it was explored:** strongest balance of public urgency, map storytelling, and lower privacy risk.
- **Why it is still alive:** it has the cleanest first-pass path to a dual-city story.
- **Park it only if:** the data join path fails or the source inventory does not hold.

## 2. Disaster evacuation + shelter / material allocation

- **Status:** Parked
- **Why it was explored:** strong government decision use case, clear cross-city support story.
- **Why it is not the current lead:** can explode in scope very quickly.
- **Revisit only if:** heat-topic joinability or source quality fails.

## 3. Elder-care + cross-district medical capacity mismatch

- **Status:** Parked
- **Why it was explored:** strong policy relevance and natural dual-city living-circle narrative.
- **Why it is not the current lead:** harder joins, more sensitivity, more ways to get stuck.
- **Revisit only if:** the team wants a policy-heavy backup after the simpler heat topic fails.

## 4. Transit resilience + external spillover

- **Status:** Rejected for first launch
- **Why it was explored:** good civic value, easy to explain as a city operations story.
- **Why it was rejected:** too easy to turn into a generic smart-city dashboard.
- **Revisit only if:** a unique source or wedge appears that makes it clearly not generic.

## 5. Youth mental health resource guidance

- **Status:** Rejected for first launch
- **Why it was explored:** important public issue.
- **Why it was rejected:** data boundary and ethics risk are too high for the first pass.
- **Revisit only if:** the project later gets a much stronger ethics and data-handling framework.

## Note

This log is intentionally conservative. It is here to save time later, not to kill good ideas forever.
