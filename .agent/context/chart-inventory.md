# Chart Inventory

目前專案支援的圖表類型 (Key值)，Mock 時請從中選擇：

| Key | 名稱 | 適用場景 |
| :--- | :--- | :--- |
| `BarChart` | 橫向長條圖 | 分類比較 |
| `ColumnChart` | 縱向長條圖 | 時序資料 |
| `DonutChart` | 圓餅圖 | 比例展示 |
| `TimelineSeparateChart` | 折線圖(比較) | 多系列獨立折線 |
| `DistrictChart` | 行政區圖 | 台北各區地圖 |
| `IndicatorChart` | 指標圖 | 單一數值卡片 |
| `TextUnitChart` | 文字數值圖 | 純文字顯示 |
