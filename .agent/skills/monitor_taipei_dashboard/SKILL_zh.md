# 監控台北城市儀表板 (中文版)

此技能提供給代理人檢查台北城市儀表板網站及後端伺服器健康狀態的指令。

**⚠️ 重要安全性警告 ⚠️**
您必須 **嚴格遵守** 以下指令：
1.  除了本文件中指定的腳本 (`monitor_dashboard.sh`) 之外，**嚴禁** 執行任何其他後端 SSH 指令。
2.  **嚴禁** 手動執行 `docker`、`df` 或其他系統管理指令。
3.  所有系統檢查邏輯都已封裝在自動化腳本中。

## 1. 網站健康檢查

**目標**：確認「捷運人流趨勢」圖表是否正常顯示數據。

**步驟**：
1.  **導航**：使用 `browser_subagent` 工具訪問 `https://citydashboard.taipei/dashboard?index=metro&city=taipei`。
2.  **驗證**：
    -   等待頁面完全加載。
    -   尋找「捷運人流趨勢」區塊。
    -   檢查圖表是否可見且不為空。
    -   檢查是否有任何錯誤訊息。
3.  **報告**：
    -   若圖表正常顯示，報告「網站檢查：正常」。
    -   若有問題（圖表空白、錯誤訊息、頁面未加載），請拍攝截圖並報告「網站檢查：失敗」及詳細原因。

## 2. 伺服器健康檢查 (自動化腳本)

**目標**：透過執行唯一允許的腳本來確認後端伺服器狀態。

**步驟**：
1.  **執行監控腳本**：
    -   使用 `run_command` 工具執行以下指令：
        ```bash
        # 若需要密碼 (環境變數 SSH_PASSWORD 已設定)
        export SSH_PASSWORD='your_password' # (若環境變數已全域設定則可省略)
        ./monitor_dashboard.sh
        ```
    -   **注意**：腳本會自動處理 SSH 連線、Docker 容器狀態檢查（包含過濾規則）、日誌擷取及磁碟空間檢查。

2.  **分析輸出**：
    -   腳本會輸出詳細的檢查結果。
    -   若腳本回傳錯誤或顯示 `[ALERT]` / `[WARNING]`，請直接引用腳本輸出的日誌或錯誤訊息。

3.  **禁止事項**：
    -   ❌ **請勿** 嘗試登入伺服器手動 Debug。
    -   ❌ **請勿** 執行 `docker ps` 或 `docker logs` (腳本已包含)。
    -   ❌ **請勿** 執行其他任何未經授權的指令。

## 3. 最終總結

將網站檢查（瀏覽器）與伺服器檢查（腳本輸出）的結果整合成一份簡潔的報告給使用者。
