全雙北區域避難量能統計規格書

一、 欄位定義表
| 欄位名稱                | 類型      | 說明              |
| ------------------- | ------- | --------------- |
| city                | String  | 縣市名稱 (臺北市/新北市)  |
| district            | String  | 行政區名稱 (如：中山區)   |
| total_capacity      | Integer | 該區總容納人數加總       |
| weak_friendly_count | Integer | 具備無障礙/弱勢友善設施之數量 |
| flood_count         | Integer | 支援水災避難之數量       |
| earthquake_count    | Integer | 支援震災避難之數量       |
| landslide_count     | Integer | 支援土石流避難之數量      |
| tsunami_count       | Integer | 支援海嘯避難之數量       |
