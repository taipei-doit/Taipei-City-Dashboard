## SYS.04 食安健康

**核心問題**：雙北的食品安全把關力度如何？醫療急救資源分布是否足夠？市民健康趨勢有哪些值得關注的警訊？

---

### 組件一：D1_雙北 AED 急救設備分布地圖

- **臺北資料集**：`臺北市AED自動體外心臟去顫器設置地點`（CSV，每月更新）
  - 欄位：場所名稱、場所地址、緯度、經度、場所分類、場所類型、AED放置地點
- **新北資料集**：`新北市公共場所AED設置資訊`（JSON/CSV/XML/KML）
- **視覺化方式**：Mapbox 點位地圖，依場所分類上色 + 各行政區 AED 密度色階圖
- **整合方式**：統一座標格式後疊圖呈現，計算「每萬人 AED 數量」做雙北行政區對比
- **對民眾的價值**：心臟驟停黃金 4 分鐘內找到最近 AED，可直接挽救生命

---

### 組件二：D2_雙北食品抽驗合格率趨勢

- **臺北資料集**：`臺北市食品衛生管理查驗工作`（CSV，每年更新）
  - 欄位：查驗件數（總計/查核/檢驗）、不符規定比率%、不符原因別（違規標示/添加物/殘留農藥等）
- **新北資料集**：`市售食品抽驗合格率`（JSON/CSV/XML，每季）+ `市售食品標示合格率`（每季）+ `新北市食品抽驗資料`（每月）
- **視覺化方式**：雙軸折線圖（抽驗件數 vs 合格率）+ 圓餅圖（不合格原因占比）
- **整合方式**：以年度或季度為 key，雙北合格率並排折線對比
- **對民眾的價值**：看見政府食安把關力度的長期趨勢，知道哪類食品問題最多

---

### 組件三：D3_雙北主要死因死亡率比較

- **臺北資料集**：`臺北市主要死亡原因`（CSV，每年）+ `臺北市主要死因死亡率`（CSV，每年）
  - 欄位：死因別、順位、死亡人數（男/女）、死亡率（每十萬人口）
- **新北資料集**：`死亡人數—主要死因`（JSON/CSV/XML，每年）+ `死亡率—主要死因`（每年）+ `標準化死亡率—主要死因`（每年）
- **視覺化方式**：橫向長條圖（十大死因排名雙北並排）+ 年度折線圖（重點死因趨勢）
- **整合方式**：以死因分類為 key，雙北年度死亡率並排對比，可結合標準化死亡率消除年齡結構差異
- **對民眾的價值**：了解雙北居民最主要的健康威脅，驅動個人健康管理意識

---

### 組件四：D4_雙北癌症死亡率對比分析

- **臺北資料集**：`臺北市主要癌症死因死亡率`（CSV，每年）+ `臺北市主要癌症死亡原因`（CSV，每年）
  - 欄位：各癌症別死亡率、死亡人數（男/女）、順位
- **新北資料集**：`死亡人數－主要癌症`（JSON/CSV/XML，每年）+ `死亡率—主要癌症`（每年）+ `標準化死亡率—主要癌症`（每年）
- **視覺化方式**：堆疊長條圖（癌症死因組成）+ 雷達圖（雙北各癌症死亡率比較）
- **整合方式**：以癌症類別為 key，雙北年度比較；可結合年齡別分析出高風險族群
- **對民眾的價值**：了解哪些癌症在雙北最致命，促進癌症篩檢意識

---

### 組件五：D5_雙北緊急救護服務效能看板

- **臺北資料集**：`臺北市各年度消防緊急救護服務`（CSV，每年）+ `臺北市消防各年度急救成功人數`（CSV，每年）+ `臺北市各年度消防緊急救護到院前心肺功能停止傷病患統計`（CSV，每年）
  - 欄位：救護出勤次數、送醫次數、OHCA人數、CPR/AED 到院前ROSC人數、康復出院人數
- **新北資料集**：`緊急救護服務`（JSON/CSV/XML，每年）+ `新北市急救責任醫院`（每年）
- **視覺化方式**：KPI 儀表板（OHCA 存活率、平均出勤次數）+ 年度趨勢折線
- **整合方式**：以年度為 key，比較雙北 OHCA 存活率 = 康復出院人數 ÷ OHCA 人數
- **對民眾的價值**：量化緊急救護品質，了解所在城市的急救水準

---

### 組件六：D6_雙北餐飲衛生分級地圖

- **臺北資料集**：`臺北市通過餐飲衛生管理分級評核業者`（CSV，每年）
  - 欄位：業者名稱、食品業者登錄字號、地址、評核結果
- **臺北補充**：`臺北市環保餐廳`（CSV）— 欄位：餐廳名稱、地址、額外環保作為
- **新北資料集**：`新北市餐飲業者(中文-106年更新)`（JSON/CSV/XML，每日）+ `新北市環保餐廳`（每季）
- **視覺化方式**：地圖標記（依評核等級/環保認證上色）+ 各區密度統計長條圖
- **整合方式**：統一 geocoding 後疊圖，計算各行政區通過率
- **對民眾的價值**：外食族選擇餐廳時，一眼辨識衛生評核通過的安心店家

---

### 組件七：D7_雙北傳染病疫苗接種率比較

- **臺北資料集**：`臺北市傳染病預防接種完成率`（CSV，每年）+ `臺北市傳染病預防接種工作`（CSV，每年）
  - 欄位：各疫苗接種率%、接種人次
- **新北資料集**：`法定傳染病—確定人數`（JSON/CSV/XML，每年）+ `新北市流感疫苗接種合約醫療院所`（每年）+ `新北市幼兒常規疫苗接種合約醫療院所`
- **視覺化方式**：群組長條圖（各疫苗接種率雙北對比）+ 年度折線（流感接種趨勢）
- **整合方式**：臺北有接種率，新北有確定人數，可計算「接種覆蓋率 vs 確診率」的交叉分析
- **對民眾的價值**：了解疫苗覆蓋程度，促進家長為兒童完成接種

### 組件八：D8_雙北藥局分布與可及性分析

- **臺北資料集**：`臺北市藥局`（CSV）
  - 欄位：機構名稱、地址、電話、x（經度）、y（緯度）
- **新北資料集**：`新北市健保特約藥局名單`（JSON/CSV/XML，每年）+ `新北市非健保特約藥局名單`（每年）
- **視覺化方式**：Mapbox 點位地圖 + Voronoi 服務範圍圖（計算最近藥局距離）+ 各區密度排名
- **整合方式**：統一座標後疊圖，計算每萬人藥局數、平均步行可達距離
- **對民眾的價值**：特別是疫情期間口罩/快篩實名制時，快速找到最近藥局

### 組件九：D9_雙北心理健康資源地圖

- **臺北資料集**：`臺北市社區心理諮商服務`（CSV）+ `臺北市心理所`（CSV）+ `臺北市可執行通訊心理諮商之心理機構`（CSV）
  - 欄位：行政區、機構名稱、地址、電話、服務時段
- **新北資料集**：`新北市心理健康服務網絡資源`（JSON/CSV/XML，每年）+ `新北市心理師駐點諮商輔導服務`（每年）+ `新北市設立心理諮商所及心理治療所`（每年）
- **視覺化方式**：地圖標記（依服務類型上色）+ 行政區涵蓋率色階圖
- **整合方式**：合併各類心理諮商資源，計算各行政區每萬人心理資源數
- **對民眾的價值**：降低求助門檻，讓有需要的市民知道身邊就有免費/低價心理資源

### 組件十：D10_雙北飲用水水質監測儀表板

- **臺北資料集**：`臺北自來水事業處供水系統內水質`（CSV，每月）+ `臺北自來水事業處各淨水場清水水質`（CSV，每月）
  - 欄位：各測站水質項目（濁度、餘氯、pH、大腸桿菌等）
- **臺北 API**：`臺北市水質監測資訊`（JSON，每 15 分鐘即時）
  - 欄位：qua_cntu（濁度）、qua_cl（餘氯）、qua_ph、longitude、latitude
- **新北資料集**：`新北市泳池水質檢驗資料`（JSON/CSV/XML，每季）+ `新北市溫泉水質檢驗資料`（每季）
- **視覺化方式**：即時水質 KPI 卡片 + 測站地圖 + 歷史月趨勢折線圖
- **整合方式**：臺北即時 API + 月報靜態數據對比；新北以季度泳池/溫泉水質為補充
- **對民眾的價值**：即時確認水龍頭出來的水安不安全，尤其颱風後特別實用

### 風險提示

| 組件 | 主要風險 | 建議對策 |
|------|---------|---------|
| AED | 新北資料標註「不更新」，可能為一次性快照 | 賽前確認 API 是否仍可拉取；準備靜態備份 |
| 食品抽驗 | 臺北年度 vs 新北季度/月度，粒度不同 | 統一為年度比較最安全 |
| 死因/癌症 | 雙北死因分類名稱可能不完全一致 | 建 mapping 表對照死因代碼 |
| 緊急救護 | 新北僅有「緊急救護服務」一個統計表，細項可能不足 | 確認欄位是否包含 OHCA 細分 |
| 餐飲衛生 | 臺北有衛生分級，新北僅業者名冊，評核標準不同 | 臺北做分級地圖，新北做業者密度圖，並排而非直接比較 |
| 疫苗接種 | 新北缺乏接種率統計，有的是院所名冊和確定人數 | 可用確定人數做「傳染病發生率」反向指標 |
| 藥局 | 臺北有座標欄位，新北可能僅有地址需 geocoding | 用 geocoding API 批量轉換新北地址 |
| 心理健康 | 雙北資料結構差異大，需人工統一分類 | 統一為「機構名/地址/類型」三欄 |
| 飲用水 | 新北缺乏自來水水質資料，僅有泳池/溫泉 | 可額外串接環保署全國飲用水水質資料作為補充 |

## SYS.06 文化共融

**核心問題**：雙北的文化資源是否分布均衡？多元族群（新住民、原住民）的文化參與及生活支持如何？觀光資源如何跨市整合讓市民和遊客受益？

---

### 組件一：B1_雙北文化資產互動地圖

- **臺北資料集**：`臺北市文化資產`（CSV）
  - 欄位：個案名稱、資產類別、資產種類、所屬主管機關、所在地理區域
- **新北資料集**：`新北市文化資產`（JSON/CSV/XML/KML，每年）
- **視覺化方式**：Mapbox 互動地圖，不同圖標區分古蹟/歷史建築/文化景觀 + 分類統計圓餅圖
- **整合方式**：統一資產類別欄位後疊圖，計算各行政區文化資產密度
- **對民眾的價值**：發掘住家附近的文化瑰寶，週末散步就能親近歷史

---

### 組件二：B2_雙北藝文活動整合日曆

- **臺北資料集**：`臺北市政府文化局文化快遞資訊`（CSV，每 6 月）+ `臺北市立美術館展覽資訊`（CSV，每 3 月）
  - 欄位：Category、Caption、StartDate、EndDate、TicketType、TicketPrice
- **新北資料集**：`新北市政府文化局藝文活動`（JSON/CSV/XML，**每日更新**）+ `新北市藝遊`（每年）
- **視覺化方式**：月曆/時間軸視圖 + 活動地點地圖 + 類別篩選器（展覽/表演/講座等）
- **整合方式**：統一日期與類別格式，合併為雙北藝文日曆
- **對民眾的價值**：一站式瀏覽雙北所有藝文活動，不再錯過好展覽好表演

---

### 組件三：B3_雙北觀光景點遊客量熱力圖

- **臺北資料集**：`臺北市觀光遊憩按月別`（CSV，每月）+ `臺北市主要觀光景點遊客數統計`（CSV，每年）
  - 欄位：各景點月度參觀人次（美術館、動物園、兒童新樂園、天文館等）
- **臺北 API**：`景點統計資料`（每月更新）
- **新北資料集**：`新北市觀光旅遊景點(中文)`（JSON/CSV/XML，每日）+ `觀光服務人員`（每年）
- **視覺化方式**：熱力地圖（遊客密度）+ 月度折線圖（季節趨勢）+ 雙北景點排名
- **整合方式**：臺北有月度人次數據做折線；新北以景點分布做空間互補呈現
- **對民眾的價值**：避開人潮尖峰出遊，發掘冷門但精彩的雙北景點

---

### 組件四：B4_雙北新住民人口與服務資源地圖

- **臺北資料集**：`臺北市新住民人口數`（CSV，每年）+ `臺北市新住民統計`（CSV）+ `臺北市婦女服務_新住民社區關懷據點`（CSV）
  - 欄位：行政區、新住民人數（依國籍別）、就業率、社區關懷據點地址
- **新北資料集**：`新住民人口`（JSON/CSV/XML，每年）+ `新住民概況`（每年）+ `外籍移工`（每年）
- **視覺化方式**：行政區色階圖（新住民人口密度）+ 圓餅圖（國籍組成）+ 服務據點標記
- **整合方式**：以行政區為 key，計算新住民占總人口比率做雙北對比
- **對民眾的價值**：讓新住民看見專屬資源分布，也讓市民理解多元文化組成

---

### 組件五：B5_雙北原住民人口與教育概況

- **臺北資料集**：`臺北市原住民戶口數`（CSV，每年）+ `臺北市原住民年齡分配`（CSV，每年）+ `臺北市各區原住民人口數`（CSV，每月）+ `臺北市原住民與新住民子女學生占學生總數比率`（CSV，每年）
  - 欄位：區域別、族別人口數、年齡分配、學生比率
- **新北資料集**：`現住原住民族戶口數`（JSON/CSV/XML，每年）+ `現住原住民族年齡分配`（每年）+ `現住原住民族種族別人口數`（每年）+ `高級中等學校及國民中小學原住民族學生數`（每年）
- **視覺化方式**：行政區色階圖 + 族群組成圓餅圖 + 年度人口趨勢折線
- **整合方式**：以年度與行政區為 key，雙北原住民人口結構並排對比
- **對民眾的價值**：以數據呈現族群分布，促進文化共融認知

---

### 組件六：B6_雙北圖書館與閱讀資源地圖

- **臺北資料集**：`臺北市立圖書館各分館暨民眾閱覽室`（CSV，每年）+ `臺北市各級學校圖書館概況`（CSV，每年）
  - 欄位：name、address、lat、lon、圖書收藏冊數、借閱人次
- **臺北 API**：`臺北市立圖書館查詢座位狀況API`（即時 10 分鐘更新）
- **新北資料集**：`新北市立圖書館地址電話一覽表`（JSON/CSV/XML）
- **視覺化方式**：地圖標記（圖書館位置）+ 氣泡大小表示藏書量 + 即時座位狀況面板
- **整合方式**：統一座標疊圖，臺北可加入即時座位；各區每萬人圖書館數對比
- **對民眾的價值**：找到最近的圖書館，即時知道有沒有空位

### 組件七：B7_雙北博物館群導覽地圖

- **臺北資料集**：`臺北市符合博物館法設立之私立博物館一覽`（CSV）+ `北美館典藏目錄`（CSV）+ `臺北市立美術館展覽資訊`（CSV，每 3 月）
  - 欄位：博物館名稱、地址、展覽標題、展覽內容
- **新北資料集**：`新北市博物館家族清單`（JSON/CSV/XML/KML，每年）+ `新北市立博物館群`（JSON/CSV/XML/KML，每年）
- **視覺化方式**：地圖導覽（博物館分布 + 當期展覽卡片）+ 類型分類篩選
- **整合方式**：合併為雙北博物館清單，配合展覽資訊做動態更新
- **對民眾的價值**：一圖看盡雙北所有博物館，搭配展覽資訊做週末行程規劃

### 組件八：B8_雙北宗教場所與社會服務分布

### 風險提示

| 組件 | 主要風險 | 建議對策 |
|------|---------|---------|
| 文化資產 | 臺北僅有名稱+區域但可能缺座標 | 用地址做 geocoding 補座標 |
| 藝文活動 | 臺北 3-6 月更新 vs 新北每日，時效差異大 | 以新北做即時日曆主體，臺北做月度/季度補充 |
| 觀光景點 | 新北缺乏遊客量統計，僅有景點清單 | 臺北做量化折線，新北做質化地圖，互補呈現 |
| 新住民 | 雙北國籍分類名稱可能不一致 | 建 mapping 對照表（越南/印尼/菲律賓等主要國籍） |
| 原住民 | 資料量大且欄位豐富，需精選指標 | 聚焦「人口數+年齡結構+學生比率」三指標即可 |
| 圖書館 | 新北僅地址電話，缺少藏書量與借閱統計 | 臺北做深度分析（藏書/借閱），新北做覆蓋率地圖 |
| 博物館 | 臺北展覽資訊豐富，新北主要為名冊 | 合併為地圖後，展覽詳情以臺北資料為主呈現 |
| 宗教 | 新北寺廟資料每月更新品質佳，臺北偏統計 | 新北做地圖點位，臺北做統計概覽，互補 |
| 公園 | 無障礙資料臺北豐富但新北較少 | 臺北做深度無障礙分析，新北做基本公園分布 |
| 市場 | 雙北都以名冊為主，缺乏「熱度」數據 | 若有 Google Maps API 可補充評論數/評分作為熱度指標 |
