資料來源
========
經濟部能源署 / 全國電力資源供需報告。
原始檔：reuse_energy/再生能源-台北.csv（與「再生能源-雙北.csv」內容相同）

欄位
----
- 年別：民國年。
  - 101–114：年度資料（年底裝置容量累計值）
  - 11502：115 年 2 月最新月度快照
- 縣市：台北市 / 新北市
- 風力（瓩）：陸域 + 離岸風力裝置容量
- 太陽光電（瓩）：屋頂型 + 地面型太陽光電裝置容量
- 其他(含水力)（瓩）：水力、生質能、地熱等

清洗規則（已套用於 clean_reuse_energy.py）
-----------------------------------------
- 三類能源固定為：風力 / 太陽光電 / 其他(含水力)
- 城市保留：台北市 / 新北市
- 年別：
  - "101"~"114" → period_sort = "{ROC:03d}-00"，視為年度
  - "11502" → period_sort = "115-02"，視為月度（最新快照）
- 單位：瓩 (kW)，整數轉換時去除千分位逗號

對應到四張前端組件
------------------
1. ColumnChart（縱向長條，three_d）— 雙北比較
   - x = 城市（臺北市 / 新北市）
   - 系列 = 三種能源類型
   - 取最新 period_sort 作為 latest snapshot
2. DonutChart（圓餅，two_d）
   - 臺北市 latest snapshot 的三種能源占比
3. TimelineStackedChart（折線堆疊，time）
   - 臺北市，僅取年度列（period_sort 結尾為 -00）
   - x 軸為 ISO 時間（{year}-01-01T00:00:00+08:00）
4. ColumnChart（縱向長條，three_d）— 臺北市年趨勢
   - x = period_label（101年、102年、…）
   - 系列 = 三種能源；資料列與 (3) 相同年度範圍
