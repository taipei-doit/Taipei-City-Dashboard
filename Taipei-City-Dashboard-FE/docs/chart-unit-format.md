# 圖表單位設定格式

各圖表的單位設定位於 `chart_config.unit`。目前支援舊格式與新格式；既有設定可繼續使用，只有需要區分不同顯示位置的單位時才需要改用新格式。

## 舊格式

將單位設為字串：

```js
unit: "次"
```

此格式會讓圖表共用同一個單位，適合各數值顯示位置的單位都相同的情況。

## 新格式

將單位設為物件，可分別指定各顯示位置使用的單位：

```js
unit: {
  value: "次", // tooltip、總計、資料標籤等數值顯示
  x: "公里",   // 數值 X 軸，例如橫向長條圖、泡泡圖
  y: "次",     // 數值 Y 軸，例如縱向長條圖或折線圖
  y1: "次",    // ColumnLineChart 左側 Y 軸
  y2: "人",    // ColumnLineChart 右側 Y 軸
  z: "人",     // BubbleChart 泡泡大小
}
```

每個欄位的用途如下：

| 欄位 | 用途 |
| --- | --- |
| `value` | tooltip、總計、資料標籤等一般數值顯示 |
| `x` | 橫向長條圖的 X 軸標題；泡泡圖的 X 軸標題與 tooltip 的 X |
| `y` | 縱向長條圖、折線圖的 Y 軸標題；泡泡圖的 Y 軸標題與 tooltip 的 Y |
| `y1` | `ColumnLineChart` 左側 Y 軸的標題，以及第一條系列的 tooltip |
| `y2` | `ColumnLineChart` 右側 Y 軸的標題，以及第二條系列的 tooltip |
| `z` | `BubbleChart` tooltip 的泡泡大小 |

## 欄位省略與單位格式

- 單位值請填字串；沒有單位時可省略對應欄位。
- 單位若是 JSON 字串，會先解析成物件，再套下面的規則。
- 舊格式字串沒有 `x`、`y` 這些欄位。只要該位置是用一般取值（含軸標題），就會直接顯示這段字串。橫向長條圖因此會出現在 X 軸，縱向長條圖與折線圖會出現在 Y 軸。長條圖(目標)的軸上不顯示單位。泡泡圖 tooltip 的 X、Y、大小也會是同一段字串；泡泡圖的軸標題不顯示字串單位。
- 物件格式先讀該位置自己的欄位。`x`、`y`、`z`、`y1`、`y2` 沒填時，退回 `value`。指定了這些欄位時，不會再改讀其他軸的欄位。
- 讀的是 `value`，而 `value` 也沒填時，才依序改用 `y`、`y1`、`y2`、`x`、`z` 中第一個有填的單位；這些都沒有時，不附加單位。
- `ColumnLineChart` 的左右軸標題，以及泡泡圖的 X、Y 軸標題，不套用上述退位，見下方表格。泡泡圖的軸標題各自獨立：有 `x` 就顯示 X 軸，有 `y` 就顯示 Y 軸。舊格式字串無法顯示在泡泡圖的軸上。
- 單位請填入單位文字本身，例如 `"公里"`，不要自行加上數值或空格；圖表會在數值與單位之間加入空格。

## 各圖表怎麼取單位

單位出現在 X 軸還是 Y 軸，由圖表元件固定決定，不會依資料方向切換。

| 圖表 | 軸標題 | tooltip、總計、資料標籤 |
| --- | --- | --- |
| `BarChart` 橫向長條圖 | X 軸，讀 `x`。字串單位直接顯示；沒有 `x` 時退回 `value`；`value` 也沒有則不顯示 | 讀 `value` |
| `ColumnChart` 縱向長條圖 | Y 軸，讀 `y`。退位與橫向長條圖相同 | 讀 `value` |
| `NegativeColumnChart` 負向長條圖 | Y 軸，讀 `y`。退位與橫向長條圖相同 | 讀 `value` |
| `TimelineSeparateChart` 折線圖(比較) | Y 軸，讀 `y`。退位與橫向長條圖相同 | 讀 `value` |
| `TimelineStackedChart` 折線圖(堆疊) | Y 軸，讀 `y`。退位與橫向長條圖相同 | 讀 `value` |
| `ColumnLineChart` 長條折線圖 | 左側讀 `y1`、右側讀 `y2`。兩邊都有字才顯示；缺一邊、或單位是字串時，軸標題為空，不退回 `value` | 第一條系列讀 `y1`，第二條讀 `y2`。字串單位會顯示；物件少了該欄時只退回 `value`，不再改讀其他軸 |
| `BubbleChart` 泡泡圖 | X 軸只在有 `x` 時顯示，Y 軸只在有 `y` 時顯示，兩邊互不影響。不退回 `value`，字串單位也不顯示在軸上 | tooltip 的 X、Y、大小分別讀 `x`、`y`、`z`。字串單位三段都顯示；少了該欄時退回 `value`；`value` 也沒有則該段不顯示單位 |
| `BarChartWithGoal` 長條圖(目標) | 圖是橫向的，軸上不顯示單位 | 資料標籤與 tooltip 都讀 `value` |
| `BarPercentChart` 長條圖(%) | 圖是橫向的，軸上不顯示單位 | tooltip 讀 `value` |
| 圓餅圖、矩形圖、雷達圖、熱力圖、行政區圖、指標圖、圖示比例圖、極座標圖、四分位圖、旭日圖、儀表板圖、地圖圖例 | 無 | 讀 `value` |
| 歷史圖 | 無 | tooltip 優先用 `history_config.unit`，沒有才用 `chart_config.unit`，讀 `value` |

量表圖、捷運行駛圖、桑基圖不讀 `chart_config.unit`。文字數值圖顯示的單位來自資料的 `icon`，也不是這個欄位。
