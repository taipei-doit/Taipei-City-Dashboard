# 圖表單位設定格式

各圖表的單位設定位於 `chart_config.unit`。目前支援舊格式與新格式；既有設定可繼續使用，只有需要區分不同顯示位置的單位時才需要改用新格式。

## 舊格式

將單位設為字串：

```js
unit: "次"
```

此格式會讓圖表共用同一個單位，適合各數值顯示位置的單位都相同的情況。

## 新格式

將單位設為物件，可分別指定各顯示位置使用的單位：

```js
unit: {
  value: "次", // tooltip、總計、資料標籤等數值顯示
  x: "公里",   // 數值 X 軸，例如橫向長條圖
  y: "次",     // 數值 Y 軸，例如縱向長條圖或折線圖
  y1: "次",    // ColumnLineChart 左側 Y 軸
  y2: "人",    // ColumnLineChart 右側 Y 軸
}
```

每個欄位的用途如下：

| 欄位 | 用途 |
| --- | --- |
| `value` | tooltip、總計、資料標籤等一般數值顯示 |
| `x` | 數值 X 軸的標題與數值，例如橫向長條圖 |
| `y` | 數值 Y 軸的標題與數值，例如縱向長條圖、折線圖 |
| `y1` | `ColumnLineChart` 左側 Y 軸的標題與數值 |
| `y2` | `ColumnLineChart` 右側 Y 軸的標題與數值 |

## 欄位省略與單位格式

- 單位值請填字串；沒有單位時可省略對應欄位。
- `x`、`y`、`y1`、`y2` 未設定時，會使用 `value` 作為該位置的單位。
- `value` 未設定時，一般數值顯示不會附加單位。
- 單位請填入單位文字本身，例如 `"公里"`，不要自行加上數值或空格；圖表會在數值與單位之間加入空格。
- 舊格式字串仍受支援，也可繼續用於 `chart_config.unit`。
